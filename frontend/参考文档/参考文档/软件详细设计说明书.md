# 2 系统结构设计及子系统划分

## 2.1 系统总体架构

系统采用前后端分离 + 微服务架构设计。

前端采用 Vue3 + Element Plus。

后端采用 Spring Boot + Spring Cloud Alibaba。

数据库采用 MySQL。

缓存采用 Redis。

服务注册中心采用 Nacos。

系统总体结构如下：

```text
[Vue前端]
     |
     v
[Spring Cloud Gateway]
     |
---------------------------------------------------
|        |          |         |        |          |
用户服务 商家服务 订单服务 支付服务 搜索服务 评价服务
     |
-------------------------
|           |            |
MySQL      Redis       Nacos
```

# 3 功能模块设计

## 3.1 用户注册登录模块

| 项目     | 内容                        |
| -------- | --------------------------- |
| 模块编号 | LA-USER-001                 |
| 模块名称 | 用户注册登录模块            |
| 输入     | 用户名、手机号、密码        |
| 处理     | 参数校验、密码加密、JWT生成 |
| 输出     | 登录结果、Token             |

### 算法描述

1. 校验手机号格式
2. 校验用户名唯一性
3. BCrypt加密密码
4. 登录成功后生成JWT

### JWT生成流程

```text
用户登录成功
    ↓
生成用户Claims
    ↓
设置Token有效期
    ↓
签名生成JWT
    ↓
返回前端
```

------

## 3.2 商家浏览模块

| 项目     | 内容             |
| -------- | ---------------- |
| 模块编号 | LA-HOME-001      |
| 模块名称 | 首页商家浏览模块 |
| 输入     | 用户定位信息     |
| 处理     | 商家推荐排序     |
| 输出     | 商家列表         |

### 推荐算法

商家排序公式：

Score = 0.4R + 0.3S + 0.2D + 0.1W

其中：

- R：商家评分
- S：月销量
- D：距离因子
- W：平台权重

## 3.3 购物车模块

| 项目     | 内容               |
| -------- | ------------------ |
| 模块编号 | LA-CART-001        |
| 模块名称 | 购物车模块         |
| 输入     | 商品ID、数量       |
| 处理     | 库存校验、金额计算 |
| 输出     | 购物车列表         |

### 金额计算

Total = \sum (price_i \times quantity_i)

### 核心流程

1. 查询商品库存
2. 校验库存是否足够
3. 更新购物车数量
4. 重新计算总金额

# 6 性能优化和安全设计

## 6.1 性能优化设计

### Redis缓存

缓存以下数据：

- 热门商家列表
- 用户Token
- 首页推荐数据

### 分页查询

所有列表接口采用分页：

```text
pageNum
pageSize
```

### 数据库优化

- 建立索引
- 避免全表扫描
- 使用连接池

------

## 6.2 安全设计

### 密码安全

密码采用 BCrypt 加密：

Hash = BCrypt(password + salt)

### JWT认证

- Token有效期24小时
- 网关统一校验

### 接口安全

- 防止SQL注入
- 参数合法性校验
- XSS过滤

# 前端接口对接说明文档

## 1. 文档目标

本说明文档用于指导后端同学基于当前前端原型完成接口接入。目标是：

- 明确前端实际依赖的接口资源
- 明确各接口的角色权限
- 明确请求字段、响应字段与用途
- 让 Spring Boot + MySQL + Redis 后端可以按文档直接接入

当前前端已具备：
- 游客 / 普通用户 / 商家 / 骑手 四角色体系
- 购物、商家经营、骑手配送基础闭环
- 本地 mock API 适配层

所有接口统一以：

```text
/api/...
```

作为前缀。

---

## 2. 前端接口入口

- 前端统一接口文件：`src/api.js`
- 页面逻辑文件：`src/app.js`

### 4.1 获取商家列表

- **方法**：GET
- **路径**：`/api/merchants`
- **角色**：游客 / 普通用户 / 商家 / 骑手
- **用途**：
  - 首页商家列表
  - 首页搜索筛选
  - 商家默认选中数据

#### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 商家 ID |
| name | string | 商家名称 |
| category | string | 商家分类 |
| rating | number | 商家评分 |
| sales | string | 销量展示文案 |
| distance | string | 距离展示文案 |
| fee | string | 配送费展示文案 |
| open | boolean | 是否营业 |
| description | string | 商家描述 |
| address | string | 商家地址 |
| phone | string | 商家电话 |
| avatar | string | 商家头像 |
| tags | string[] | 商家标签 |
| products | array | 商品列表 |

## 6. 角色权限说明

### 6.1 游客
- 可访问：首页、搜索、商家详情、商品详情
- 不可访问：购物车、订单、商家后台、骑手工作台
- 购买相关操作需先登录普通用户账号

### 6.2 普通用户
- 可访问：首页、购物车、订单、个人中心、商家详情、商品详情
- 可执行：加购、下单、支付、取消、确认收货、评价

### 6.3 商家
- 可访问：首页（商家视角）、商家资料、商家后台、商品编辑页
- 可执行：店铺资料维护、商品新增/编辑/删除、库存调整、订单处理
- 不可执行：购物车、下单、普通用户支付流程

### 6.4 骑手
- 可访问：首页（骑手视角）、骑手资料、骑手工作台
- 可执行：查看待抢单、查看我的任务、接单、已取餐、完成配送、切换在线/离线
- 不可执行：购物车、下单、商家商品管理

## 7. 动态功能说明

### 7.1 首页搜索与推荐
- 首页搜索栏支持跳转搜索页
- 搜索结果会回填首页推荐筛选
- 搜索栏支持吸顶

### 7.2 购物车与下单
- 加购实时更新购物车
- 优惠券自动匹配
- 下单后进入订单列表

### 7.3 商家经营链路
- 店铺资料可编辑并保存
- 商品可新增、编辑、删减、改库存
- 商家后台可处理本店订单

### 7.4 骑手配送链路
- 骑手可查看待抢单 / 我的任务 / 已完成历史
- 骑手可接单、已取餐、送达完成
- 离线状态下不展示待抢单

## 8. 后端接入建议

1. 按当前接口路径实现真实后端服务
2. 保持 JSON 字段名称与本说明文档一致
3. 订单相关字段建议保留：`merchantId`、`riderId`、`riderName`、`etaMinutes`
4. 商品、订单、骑手任务应使用数据库驱动
5. 登录与注册建议接入 JWT + 密码哈希
6. 后续可将商家、骑手、用户拆分为独立 Controller / Service / Entity

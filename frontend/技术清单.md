# 生活助手平台项目技术清单

本文记录当前交付版本实际使用的技术栈和建议学习顺序。历史课程材料中的 Vue、Element Plus、Maven 等内容仅代表早期设想；当前代码以 React、Vite、Gradle、Spring Cloud 微服务为准。

## 一、前端技术栈

### 1. React 18

项目位置：`frontend/src/`

学习内容：

- 函数组件。
- JSX。
- Hooks。
- 组件拆分。
- 表单和列表渲染。
- 条件渲染与加载/错误状态。

项目对应文件：

- `src/main.jsx`
- `src/pages/*.jsx`
- `src/components/ReviewImageGallery.jsx`

### 2. React Router

学习内容：

- `BrowserRouter`。
- `Routes` / `Route`。
- `Navigate`。
- 路由参数。
- 登录态保护路由。

项目对应能力：

- 消费者页面：`/cart`、`/checkout`、`/orders`、`/coupons`、`/profile`。
- 商家页面：`/merchant-center`。
- 骑手页面：`/rider-center`。
- 管理员页面：`/admin-center`。

### 3. Axios 与 API 客户端

项目位置：`frontend/src/utils/api.js`

学习内容：

- Axios 实例。
- 请求超时。
- Authorization 请求头。
- 统一错误处理。
- `Result<T>` 和 `PageResult<T>` 响应展开。
- `VITE_API_BASE_URL` 环境变量。

### 4. Vite / Vitest / Playwright

项目位置：`frontend/package.json`、`frontend/vite.config.js`、`frontend/playwright.config.js`

学习内容：

- Vite 开发服务和生产构建。
- Vitest 单元测试。
- Testing Library 页面测试。
- Playwright E2E。
- E2E mock API 与真实 Gateway 冒烟的区别。

常用命令：

```powershell
cd frontend
npm.cmd run build
npm.cmd run test:ci
npm.cmd run e2e
```

## 二、后端技术栈

### 1. Java 21 与 Spring Boot 3.4

学习内容：

- Controller / Service / Mapper 分层。
- RESTful API。
- 参数校验。
- 统一响应 `Result<T>`。
- 全局异常处理。
- Spring 事务。
- Actuator 健康检查。

项目对应目录：`services/*-service/`

### 2. Spring Cloud Gateway

项目位置：`services/api-gateway/`

学习内容：

- Gateway 路由定义。
- 路由优先级。
- Path Predicate。
- 服务名负载均衡路由。
- 前端统一 `/api` 入口。

重点：`/api/user/reviews` 需要优先路由到 `engagement-service`，不能被 `/api/user/**` 泛路由截获。

### 3. Nacos Discovery / Config

学习内容：

- 服务注册与发现。
- 配置中心。
- 公共配置和服务级配置拆分。
- 配置发布脚本。

文档：`docs/nacos-config-center.md`

### 4. OpenFeign 与服务间调用

学习内容：

- Feign Client。
- 服务名调用。
- 超时配置。
- Feign 日志。
- 内部接口 DTO。
- 降级和异常传递。

文档：`docs/feign-basic-governance.md`

### 5. Sentinel

学习内容：

- Gateway 入口限流。
- 业务服务限流。
- Feign 熔断规则。
- 规则数据源。
- 无 Dashboard 的云端部署策略。

文档：`docs/sentinel-governance.md`

## 三、数据与存储

### 3. Redis 7

项目用途：

### 4. 图片存储

- 文件类型和大小校验。

文档：`docs/oss-image-storage.md`

## 四、部署与工程化

### 1. Gradle

项目使用 Gradle wrapper 和根目录多项目配置：

- `settings.gradle`
- `services/*/build.gradle`
- `services/common-lib/build.gradle`

常用命令：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\test-microservices.ps1
```

### 2. Docker Compose

用于本地完整运行 MySQL、Redis、Nacos、Gateway、业务服务和前端。

常用命令：

```powershell
copy .env.example .env
$env:COMPOSE_PARALLEL_LIMIT=1
docker compose up -d mysql redis nacos
docker compose run --rm db-init
docker compose up --build
```

### 3. Kubernetes / K8s

项目位置：`k8s/`

学习内容：

- Deployment。
- Service。
- ConfigMap。
- Secret。
- NodePort。
- HPA。
- readiness/liveness probe。

部署脚本：`scripts/deploy-kind.sh`

### 4. GitHub Actions

项目位置：`.github/workflows/ci.yml`

覆盖内容：

- 后端微服务矩阵测试。
- 前端单测。
- Playwright E2E。
- 前端构建。
- main 分支容器构建和 K8s 部署。
- 失败诊断归档。

## 六、建议学习优先级

### 第一阶段：能跑起来

1. Docker Compose 启动流程。
2. 前端 `npm run dev` / `npm run build`。
3. API Gateway 和 `/api` 路由。
4. 常用测试账号和核心业务流程。

### 第二阶段：能改业务

1. React 页面组件。
2. `frontend/src/utils/api.js`。
3. Spring Boot Controller / Service / Mapper。
4. MyBatis-Plus。
5. MySQL 多 schema 数据边界。

### 第三阶段：能做联调和治理

1. JWT 鉴权和角色保护。
2. OpenFeign 内部接口。
3. Nacos Discovery / Config。
4. Sentinel 限流、熔断和降级。
5. K8s 部署、HPA 和故障实验。

## 七、最终能力目标

| 能力 | 目标 |
| --- | --- |
| 前端开发 | 能维护 React 页面、路由和 API 调用。 |
| 后端开发 | 能独立开发微服务 REST 接口和内部接口。 |
| 数据库设计 | 能维护多 schema 表结构和服务边界。 |
| 登录鉴权 | 能理解 JWT、角色权限和运行时状态校验。 |
| 微服务治理 | 能配置 Gateway、Feign、Nacos 和 Sentinel。 |
| 测试验证 | 能执行并解释前端、后端、E2E 和冒烟测试。 |
| 部署运维 | 能用 Docker Compose/K8s 运行完整系统。 |

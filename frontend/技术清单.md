# 生活助手平台项目技术学习清单

## 一、后端技术栈

### 1. 后端整体架构

#### （1）Spring Boot 框架

学习内容：

- Spring Boot 项目创建与启动
- 自动配置原理
- 配置文件（application.yml）
- Bean 管理与依赖注入（IOC）
- AOP 面向切面编程
- Spring Boot 多环境配置
- 异常统一处理
- 参数校验（Validation）
- 日志管理（Slf4j）

掌握目标：

- 能快速搭建后端项目
- 能开发 RESTful API
- 能完成基础业务开发

------

#### （2）Spring Cloud 微服务架构

学习内容：

- 微服务基本思想
- 服务拆分原则
- Spring Cloud Alibaba 体系
- 微服务通信方式
- OpenFeign 服务调用
- Gateway 网关
- Nacos 服务注册与配置中心

重点学习：

- 服务注册与发现
- 网关路由转发
- JWT 鉴权
- 请求拦截器
- 配置中心

掌握目标：

- 能搭建简单微服务系统
- 能完成服务间调用
- 能实现统一登录鉴权

------

## 二、控制层（Controller）

### 1. Spring Boot Controller 开发

学习内容：

- Controller 编写
- RESTful 风格接口
- GET / POST / PUT / DELETE
- 请求参数接收
- JSON 数据返回
- Result 统一返回格式
- Swagger/OpenAPI 接口文档

重点：

```java
@RestController
@RequestMapping("/user")
```

掌握目标：

- 能开发完整 CRUD 接口
- 能规范返回数据格式

------

### 2. 微服务相关控制技术

学习内容：

- Gateway 网关配置
- JWT 登录认证
- Token 校验
- 登录拦截器
- 全局过滤器 Filter
- 跨域处理（CORS）

重点掌握：

- 登录后 Token 签发
- 请求鉴权流程
- 网关统一认证

------

## 三、业务层（Service）

学习内容：

- Service 层开发规范
- 业务逻辑分层
- 接口与实现类
- Spring 事务管理（@Transactional）
- 订单业务事务处理

重点：

- 下单事务
- 库存扣减
- 支付状态修改

掌握目标：

- 能实现完整业务流程
- 能处理事务一致性

------

## 四、数据层（Database）

## 1. MySQL 数据库

学习内容：

- MySQL 基础语法
- 增删改查（CRUD）
- 多表关联查询
- 索引
- 外键关系
- 数据库设计（三范式）

重点：

- 用户表
- 订单表
- 商品表
- 购物车表

掌握目标：

- 能设计数据库
- 能编写业务 SQL

------

## 2. MyBatis-Plus 持久化技术

学习内容：

- MyBatis-Plus 基础使用
- Mapper 编写
- BaseMapper
- 条件构造器 Wrapper
- 分页插件
- 逻辑删除
- 自动填充

重点：

```java
QueryWrapper<User> wrapper = new QueryWrapper<>();
```

掌握目标：

- 能快速完成数据库 CRUD
- 能减少 SQL 编写量

------

## 3. Redis 缓存

学习内容：

- Redis 基础
- String / Hash / List
- Redis Java 客户端
- Spring Boot 集成 Redis
- RedisTemplate
- Session/Token 缓存
- 热点数据缓存

项目中主要用途：

- 登录 Token
- 热门商家缓存
- 购物车缓存

掌握目标：

- 能实现简单缓存系统
- 能提升接口性能

------

## 4. 数据源与连接池

学习内容：

- 数据库连接池原理
- Spring Boot 默认 HikariCP
- Druid 数据池

推荐：

- 初学直接使用 Spring Boot 默认连接池
- 有余力再学习 Druid 监控

掌握目标：

- 能完成数据库连接配置
- 理解连接池作用

------

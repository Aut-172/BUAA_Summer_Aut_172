# 前端联调与验收清单

## 1. 目的

本清单用于团队成员在联调或交付前快速验证：

- 页面能否正常运行
- 各角色功能是否可用
- 主要业务链路是否形成闭环

---

## 2. 启动检查

- [ ] 已在 `frontend/` 下执行 `npm install`
- [ ] 已在 `frontend/` 下执行 `npm run dev`
- [ ] 浏览器能打开 `http://127.0.0.1:5173/`
- [ ] 已执行 `npm run build` 且构建成功
- [ ] 如需真实后端联调，已启动 Gateway 和业务微服务
- [ ] `http://localhost:8080/actuator/health` 可访问

---

## 9. 订单状态闭环检查

推荐验收顺序：

1. 普通用户下单
2. 普通用户支付订单
3. 骑手接单
4. 骑手已取餐
5. 商家或骑手推进订单状态
6. 骑手完成配送
7. 普通用户确认收货
8. 普通用户评价商品

确认点：
- [ ] 各角色看到的订单状态一致
- [ ] 骑手名和 ETA 能在订单中展示
- [ ] 已完成订单可评价

## 12. 交付建议

提交给队友或后端前，建议：

- 再跑一次 `npm run build`
- 确认所有账号都可登录
- 确认前端 `/api` 指向当前 Gateway
- 确认接口说明文档已和代码保持一致
- 确认前端 E2E mock 结果和真实 Gateway 冒烟结果没有混用

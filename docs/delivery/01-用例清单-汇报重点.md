## 2. 最终汇报建议重点

建议主讲 8 个用例：

1. UC07 下单：最能体现微服务拆分后的跨服务校验、库存预占、锁券和订单本地事务。
2. UC08 支付：体现结算服务与订单服务之间的状态推进和支付流水。
3. UC11 评价：体现互动服务如何校验订单完成、写评价、标记订单明细已评价。
4. UC14 商品规格库存：体现商家商品服务是商品和库存事实源。
5. UC16 骑手配送：体现履约服务与订单状态机协作。
6. UC18 管理员主体管理：体现多角色权限和后台治理能力。
7. UC20 商家看板：可串联故障处理报告，展示依赖订单服务故障时的降级能力。
8. UC21 订单会话：体现消息参与人校验和多角色协作。

## 3. 用例覆盖结论

- UC01-UC21 均有前端页面、API 客户端或后端接口覆盖。
- 微服务测试报告覆盖 Gateway、六个业务服务和内部接口，最近报告为 84/84 通过。
- B 侧专项测试覆盖商家、用户、履约、互动边界，最近报告为 63/63 通过。
- Playwright E2E 默认使用 mock API 验证页面流程；真实 Gateway 验收需使用完整运行环境。

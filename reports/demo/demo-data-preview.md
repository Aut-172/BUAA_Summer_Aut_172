## 11. 看板展示重点

| 看板 | 需要出现的数据 |
| --- | --- |
| 消费者首页 | 至少 2 个 Food 商家、2 个 Drinks 商品、1 个关闭商家被过滤 |
| 商家仪表盘 | 今日营收、总营收、总订单数、近 14 日营收折线；例如 Campus Kitchen 可显示今日营收 49.00、总营收 1779.00、总订单数 81 |
| 商家仪表盘 | Tea Corner 可显示今日营收 13.00、总营收 1033.00、总订单数 60 |
| 骑手仪表盘 | 今日接单数、配送中、已完成、已配送任务 |
| 管理员工作台 | 用户、商家、骑手、订单各有活跃和异常样本 |
| 消息页 | 至少 2 个会话线程、1 条未读消息 |

## 12. 建议的演示顺序

1. `demo / 123456` 登录。
2. 首页看商家和推荐。
3. 搜索 `rice` / `tea` 看联想。
4. 打开 `Campus Kitchen`，加入购物车，切换地址。
5. 使用 `60002` 结算并支付。
6. 看订单详情、配送进度、确认收货。
7. 提交评价。
8. 切到消息页，看线程和未读数刷新。
9. 切商家、骑手、管理员账号看对应看板。
